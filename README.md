# Fin-Check Bot

Telegram-бот, который проверяет арифметику в текстовых финансовых отчётах
прямо в рабочем чате и по команде `/svodka` делает сводку по всем отчётам.

## Как это работает

- Бот читает сообщения чата. Сообщения, похожие на отчёт (есть цифры и
  финансовые слова), отправляются в Claude на проверку.
- Если суммы не сходятся — бот отвечает реплаем «⚠️ Нашёл расхождения» с
  конкретикой. Если всё в порядке — «✅ суммы сходятся».
- Все распознанные отчёты сохраняются, `/svodka день|неделя|месяц` выдаёт
  аналитическую сводку за период (по умолчанию — неделя).

## Настройка бота в BotFather

1. `/newbot` → получите `BOT_TOKEN`.
2. **Обязательно:** `/setprivacy` → выберите бота → **Disable**. Без этого бот
   не видит обычные сообщения в группе. (Альтернатива — сделать бота
   администратором чата.)
3. Добавьте бота в рабочий чат.

## Деплой на Railway

1. Создайте проект из этого репозитория (`railway init` + `railway up`, либо
   через GitHub).
2. В сервисе добавьте **Volume** и примонтируйте его в `/data` — иначе история
   отчётов будет стираться при каждом деплое.
3. Переменные окружения:
   - `BOT_TOKEN` — токен из BotFather
   - `ANTHROPIC_API_KEY` — ключ Anthropic
   - `DB_PATH` = `/data/reports.db`

## Локальный запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
BOT_TOKEN=... ANTHROPIC_API_KEY=... .venv/bin/python main.py
```

Тесты: `.venv/bin/python -m pytest tests/`

## Ограничения (пока)

- Понимает только текстовые отчёты — Excel/PDF/фото не разбирает.
- Не сверяет с планом/бюджетом, только внутреннюю арифметику.
- Работает в любом чате, куда его добавят (нет привязки к одному чату).
