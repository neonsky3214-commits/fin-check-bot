# Fin-Check Bot — дизайн

Дата: 2026-08-17. Утверждён пользователем в чате.

## Цель

Telegram-бот, которого добавляют в рабочий чат. Он автоматически проверяет
арифметику в текстовых финансовых отчётах и по команде выдаёт сводку по всем
накопленным отчётам.

## Поведение

1. Бот читает все текстовые сообщения группы (privacy mode выключен или бот —
   админ).
2. Быстрый локальный фильтр: сообщение считается кандидатом в отчёты, если в нём
   есть минимум 2 числа и хотя бы одно финансовое ключевое слово (итого, расход,
   выручка, руб, ₽ и т.п.). Остальные сообщения не тратят API-вызовы.
3. Кандидат отправляется в Claude API: модель определяет, отчёт ли это, и
   пересчитывает всю арифметику (суммы, итоги, проценты).
4. Бот отвечает реплаем на отчёт: «✅ суммы сходятся» либо «⚠️ расхождения: …»
   с конкретикой. На не-отчёты не отвечает.
5. Каждый распознанный отчёт сохраняется в SQLite (chat_id, автор, дата, текст,
   итог, ошибки).
6. Команда `/svodka [день|неделя|месяц]` (по умолчанию неделя) — Claude
   формирует сводку по отчётам этого чата за период.

## Стек

- Python 3.12, aiogram 3 (long polling), Anthropic SDK (claude-sonnet-5).
- SQLite; путь через `DB_PATH` (на Railway — volume, примонтированный в /data).
- Деплой: Railway, worker-процесс.

## Переменные окружения

- `BOT_TOKEN` — токен из BotFather.
- `ANTHROPIC_API_KEY` — ключ Anthropic.
- `DB_PATH` — путь к базе (по умолчанию `/data/reports.db`, локально —
  `./reports.db`).

## Вне скоупа

Excel/PDF/фото, сверка с бюджетом, ограничение по конкретному чату,
редактированные сообщения.
